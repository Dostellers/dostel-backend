# DOS-253: Cloudbeds as Inventory Authority Layer - Messaging

**Priority**: Medium  
**Owner**: CMO  
**Requestor**: Market Researcher  
**Date**: Aug 1, 2026

## Problem
Dostel needs to communicate that it leverages enterprise-grade infrastructure (Cloudbeds) for reliability while differentiating on community-driven workflows. Avoid framing as "just another Cloudbeds hostel."

## Goal
Create messaging that positions Dostel as: "Enterprise-grade PMS powering Dosteller-led community experiences" — highlighting trust, reliability, and community sovereignty.

## Requirements
1. **Core Message**: "We use Cloudbeds for rock-solid bookings, payments, and OTA sync — so we can focus on what matters: Dosteller-hosted events, skill shares, and verified stays."
2. **Landing Page Banner**: On homepage and hostel pages: "Powered by Cloudbeds. Built for Dostellers."
3. **FAQ Section**: 
   - Q: "Do you use Cloudbeds?" A: "Yes — for secure payments, real-time availability, and 300+ OTA connections. This lets us invest in Dosteller reputation, event workflows, and community trust."
   - Q: "How is this different from other Cloudbeds hostels?" A: "We layer Dosteller-specific workflows on top: member approvals, contribution credits, and verified host stories."
4. **Blog/Content**: "Why we didn’t rebuild the PMS (and why that’s good for you)" — explaining build/buy tradeoff.
5. **Internal Training**: Talk script for support/ops on explaining the architecture.

## Competitive Benchmark
- The Hosteller: Proprietary PMS + loyalty wallet (https://www.thehosteller.com/membership/)
- Zostel: Proprietary app + $Zo rewards (https://www.zostel.com/)
