# AsiaTech Hospitality PMS — Research Notes

Source: Wayback capture of asiatech.in (Dec 2024)

## Product Suite
| Product | Description |
|---------|-------------|
| Hotel Channel Manager | Manage all OTAs from one screen, single-click rate/availability sync |
| Property Management System | Day-to-day ops: reservations, check-in/out, billing |
| Revenue Management | Dynamic pricing automation (occupancy, competitor rates, demand, events) |
| Booking Engine | Direct commission-free bookings on hotel website |
| Restaurant Management | Inventory lifecycle, food cost tracking, smart ordering |
| Web Development | Custom web app dev |
| Digital Marketing | Brand storytelling, SEO |

## Key Differentiators
- Since 2014 — mature SSAS hospitality platform
- 99.5% customer satisfaction, 97.5% support satisfaction, 99.9% uptime
- WhatsApp-based support (fast resolution)
- One-stop solution: PMS + Channel Manager + Booking Engine + Revenue Management
- Used by groups of hotels, standalone properties, restaurants

## Relevance to Dostel

### Direct Gaps (can ship within 2 sprints)
1. **Channel Manager** — Dostel needs OTA sync (Hostelworld, Booking.com, Airbnb). Currently no integration.
2. **Dynamic Pricing** — No revenue management model. Prices are static.
3. **Restaurant POS** — Dostel has Altaf's Cafe on property. No inventory/billing module.
4. **WhatsApp/Notifications** — No guest communication channel built in.

### Future Opportunities
- Mobile guest app (AsiaTech has mobile app for download)
- Multi-property support (Dostel scaling beyond single Vattakanal property)
- Automated review/rating management
- Housekeeping/maintenance module
