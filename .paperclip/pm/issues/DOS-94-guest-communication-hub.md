# DOS-94: Guest Communication Hub

**Priority**: High  
**Source**: Competitive Gap (OTA guests use app-based messaging)  
**Owner**: Product  

## Description
Implement lightweight in-app communication for guests:
- Real-time house rules, weather alerts, and peer-to-peer coordination
- Start with Hostelworld chat widget as interim solution
- Future native GraphQL subscription for announcements

## Acceptance Criteria
- [ ] Chat widget integrated for pre-checkin/post-checkout
- [ ] Notifications visible in guest inbox
- [ ] Ability to send housewide announcements
- [ ] Reference: Hostelworld customer support use cases

## Metrics
- Target: 40% reduction in no-shows via proactive alerts
- Track: Usage frequency of chat feature
- Measure: Time-to-resolution for guest queries
