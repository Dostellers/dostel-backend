# DOS-95: Sustainability Impact Tracker

**Priority**: Medium  
**Source**: Brand Differentiator (Bob & Tanya, 1985 ecological restoration)  
**Owner**: Product  

## Description
Build backend service to log eco‑actions and expose via GraphQL:
- Track trees planted, waste segregated, volunteer hours
- Show aggregates on Dorteller profile and in‑room tablets
- Start with manual entry; later integrate with partner NGOs

## Acceptance Criteria
- [ ] GraphQL query `impactStats` available
- [ ] Display on Dorteller dashboard (e.g., "Your impact: 5 trees planted")
- [ ] Admin UI for manual entry of eco‑actions
- [ ] Data migrated to public sustainability page

## Metrics
- Short‑term: 1,000 eco‑actions logged in first 6 months
- Long‑term: Increase guest satisfaction score by 0.4 points via perceived impact
- Benchmark: Compare engagement vs. typical sustainability programs

## Dependencies
- Requires: Dorteller status data for tier‑based rewards (DOS‑91)
- Frontend: Profile page update to show impact metrics
- Ops: Staff training on waste‑segregation and tree‑planting tracking
