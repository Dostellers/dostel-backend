## Research: Remote Worker Booking Optimization

### Context
- Target audience: Remote workers (35% of travelers) and Dostellers (long-stay community)
- Current pain points: inflexible booking hours, lack of workspace integration

### Opportunities
1. **Flexible Booking Windows**
   - Allow 24/7 booking via GraphQL API
   - Integrate with tools like Calendly for remote workers

2. **Workspace-perk Bundles**
   - Offer free workspace access with stays >7 days
   - Create Dosteller-exclusive activity calendar

3. **Dosteller Benefits**
   - Implement loyalty points for community activities
   - Tiered membership perks tied to stay duration

### Assumptions
- Remote workers prioritize workspace reliability
- Dostellers value community engagement over price
