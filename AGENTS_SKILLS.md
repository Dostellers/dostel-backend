# Dostel Project - Agentic Developer Skills and Tasks

This document outlines the different skill sets and corresponding tasks that agentic developers can work on for the Dostel project.

## 1. Backend Developer (Node.js/GraphQL)

### Skills Required:
- Node.js/Express
- GraphQL (Apollo Server)
- MongoDB/Mongoose
- REST API design
- Authentication & Authorization (JWT, bcrypt)
- AWS/AWS Services (S3, SES, etc.)
- Testing (Jest, Mocha)

### Tasks:
- User authentication and authorization system
- Hostel/room management APIs
- Booking and reservation system
- Payment integration (Razorpay/Stripe)
- Review and rating system
- Admin dashboard APIs
- Notification system (email/SMS)
- File upload and management (images, documents)
- Search and filtering optimization
- Database optimization and indexing
- API documentation and versioning
- Security auditing and penetration testing

## Suggested Workflow for Agentic Developers:

1. **Task Assignment**: Use the scheduler to assign specific tasks based on agent skills
2. **Daily Standup**: Brief status updates on progress and blockers
3. **Code Review**: Peer review process for all code changes
4. **Testing**: Automated and manual testing of changes
5. **Deployment**: Continuous deployment to staging/production
6. **Monitoring**: Track performance and error metrics
7. **Feedback Loop**: Incorporate user feedback and metrics into next iteration

## Communication Protocols:

- Use structured status reports for task completion
- Maintain detailed documentation in AGENTS.md files
- Use standardized commit message formats
- Implement code review checklists
- Schedule regular synchronization meetings
- Share progress through defined channels
